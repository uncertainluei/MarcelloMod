# MarcelloMod
(currently for version 1.21.1, and the Fabric modloader, ports to newer versions/other modloaders will be considered after it is in a finished state.)

Pseudo-remake and overhaul of a Minecraft mod initially created by MoldyGangstaHero using MCreator, being simply a parody mod on a YouTube user by the name of *Blood*/*MeltingRED3* (Marcello), and also references to similar 2020 stuff.

The mod in itself is currently incomplete (a lot of the current world generation additions are not final, and there is a lot of stuff missing or not fully fleshed out), so I'd not advise you to play the mod if you're searching for survival content.

If you do want to play the original Minecraft mod this is based on (and is playable for the most part), download it from here. https://moldygh.itch.io/marcellomod
(Requires Forge 1.15.2)
